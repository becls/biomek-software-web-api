# If

| Property | Value |
|----------|-------|
| stepType | `"If"` |
| Category | Container (exact children) |
| Terminator | N/A (children are exact-match Named Containers, each of which ends with `"End"`) |
| Compatible Hardware | All |

## Behavior Summary

At runtime the If step evaluates a VBScript/JScript expression and then executes exactly one of two branches: the Then branch (first Named Container child) if the condition is true, or the Else branch (second Named Container child) if the condition is false. The condition string is auto-prefixed with `=` if it does not already start with one, then evaluated as a script expression. An empty condition causes a runtime error. The If step is placed between operational steps inside any free-form container.

## Parameters Reference Table

| Key | Type | Units | Required | Default | Description |
|-----|------|-------|----------|---------|-------------|
| `condition` | `expression-capable string` | — | Yes | `""` | A VBScript or JScript expression to evaluate. If it does not start with `=`, the runtime auto-prefixes one. Begin an expression with `==` for JScript evaluation. The result is coerced to boolean: truthy executes the Then branch, falsy executes the Else branch. |

> _Universal base keys (`caption`, `dynamic?`, `stepUI`, `disabled`, …) apply to this step but are omitted here — see [Base Keys & Serialization Conventions](00-Base-Keys-and-Conventions.md)._

## Enumerated / Constrained Values

No enumerated value constraints — `condition` accepts any valid script expression.

## Cross-Field Validation Rules

1. `condition` **must** be a non-empty string.
2. `condition` **must** be a valid VBScript/JScript expression that can be coerced to boolean.
3. Expressions can reference variables defined by enclosing Let, Loop, Set Global, or Scripted Let steps. The `=` prefix marks the *whole condition* as an expression (not each reference individually) — e.g. `=MyVar > 10` treats the entire string as an expression that dereferences `MyVar`.

## Structural Context

The If step is an **exact-children container** with exactly 2 `"Named Container"` children:

- **Index 0**: Then branch — `"Named Container"` with caption `"Then"`.
- **Index 1**: Else branch — `"Named Container"` with caption `"Else"`.

Each Named Container is itself a free-form container that must end with `"End"`. You may place any steps inside each branch before its `"End"` terminator.

**Constraints**:

- `subSteps` must contain exactly 2 elements.
- Both elements must be of type `"Named Container"`.
- Each Named Container's own `subSteps` must end with `"End"`.
- A branch with no operational steps is valid — it can contain just `"End"`.

## Canonical Examples

Minimal If with empty branches:

```json
{
  "stepType": "If",
  "parameters": {
    "condition": "=SampleCount > 0"
  },
  "subSteps": [
    {
      "stepType": "Named Container",
      "parameters": { "caption": "Then" },
      "subSteps": [
        { "stepType": "End", "parameters": {} }
      ]
    },
    {
      "stepType": "Named Container",
      "parameters": { "caption": "Else" },
      "subSteps": [
        { "stepType": "End", "parameters": {} }
      ]
    }
  ]
}
```

If with operational steps in both branches:

```json
{
  "stepType": "If",
  "parameters": {
    "condition": "=Volume > 50"
  },
  "subSteps": [
    {
      "stepType": "Named Container",
      "parameters": { "caption": "Then" },
      "subSteps": [
        { "stepType": "Transfer", "parameters": {} },
        { "stepType": "End", "parameters": {} }
      ]
    },
    {
      "stepType": "Named Container",
      "parameters": { "caption": "Else" },
      "subSteps": [
        { "stepType": "Pause", "parameters": {} },
        { "stepType": "End", "parameters": {} }
      ]
    }
  ]
}
```

If using a variable from an enclosing Loop:

```json
{
  "stepType": "If",
  "parameters": {
    "condition": "=IterationCount > 0"
  },
  "subSteps": [
    {
      "stepType": "Named Container",
      "parameters": { "caption": "Then" },
      "subSteps": [
        { "stepType": "Transfer", "parameters": {} },
        { "stepType": "End", "parameters": {} }
      ]
    },
    {
      "stepType": "Named Container",
      "parameters": { "caption": "Else" },
      "subSteps": [
        { "stepType": "End", "parameters": {} }
      ]
    }
  ]
}
```

## Common Mistakes

- **Placing operational steps directly inside `If`**: they must live inside the Then/Else Named Containers, not as direct children of `If`.
- **Substituting `Group` (or another container) for a branch**: both children must be `"Named Container"` — no other type is accepted by the exact-children structural rule.
- **Stylistic: prefer the `=` prefix on `condition`**: runtime auto-prefixes when it's missing, so `"Volume > 50"` and `"=Volume > 50"` both work. Not a correctness issue — the leading `=` marks the string as an expression.
- **Swapping Then and Else**: index 0 is Then, index 1 is Else — order is positional, not by any child key.
