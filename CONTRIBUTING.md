# Contributing to the Biomek Software Web API

The Biomek Software Web API is under active development. We welcome
suggestions from anyone interested in helping make it better.

This repository hosts the public-facing materials for the Biomek Software Web
API, the Biomek Software JSON format, and the Biomek Software Web API Admin Tool.

The implementation itself lives in a separate, internal repository, so most
suggestions here will fall into one of the following categories:

* **Documentation fixes** &mdash; corrections, clarifications, or missing
  details in the specifications or accompanying prose.
* **Code examples** &mdash; new examples, or fixes to existing ones.
* **Feature requests and API feedback** &mdash; suggestions for new
  endpoints, changes to existing endpoints, or improvements to request and
  response shapes. These are best filed as issues so they can be discussed
  before any work begins.

Before investing significant effort in any proposed contribution, consider
running the idea by one of the maintainers for guidance and advice. Note
that not all issues will be fixed or investigated and not all pull requests
will be accepted; the final decision on all proposed contributions lies with
the maintainers of the repository and only the maintainers of the repository
can modify the publicly accessible main branch.

Please keep in mind the following guidance when preparing suggestions:

* When proposing a new feature, we first look for a way to achieve the
  same effect with existing endpoints or smaller extensions that are more
  generally applicable.

* For code examples, follow the structure (including indentation) of any
  existing examples in the language you are contributing to; if none exist,
  style as desired and we can address any concerns as part of the pull request.
  Keep examples as clean, clear, and short as possible while still being
  realistic.

* If producing a proposed pull request, describe changes in the git commit
  messages and GitHub pull request description. These records should clearly
  explain the motivation for the change as well as what was changed.
